## Projects

### baitbox

A small honeypot for homelab setups. It uses a fake filesystem and logs interactions so I can look at what happens, rather than trying to block anything.

- Fake filesystem
- Interaction logging
- Straightforward deployment

### FamilyFinance

A budgeting app for keeping household transactions and spending in one place. The idea is to make day-to-day budgeting less awkward than managing a pile of spreadsheets, with an interface that can be self-hosted.

- Transaction tracking
- Family budgeting
- Self-hosting in mind

### Currently working on

- `biolink-pro`
- `nexuspro`
